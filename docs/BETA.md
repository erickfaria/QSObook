# Previous beta installation link

The maintained installation and update instructions are now in [INSTALL.md](INSTALL.md), including stable **v0.1.0**, Raspberry Pi, trusted LAN/VPN access, optional passwords and backups.

Existing beta installations keep the same Compose project and data volume. Do not delete or reinstall the notebook to update. Stable v0.1.0 uses the same schema 7 as beta 5. Historical beta images and release assets remain available under [Releases](https://github.com/erickfaria/QSObook/releases).

Current source uses schema 8 for optional RadioID enrichment. See the installation guide before leaving a published schema-7 image; downgrading requires a pre-upgrade backup.
